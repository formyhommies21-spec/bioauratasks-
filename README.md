# BIOAURA · виджет задач

Десктопный виджет в стиле TickTick для модуля «Задачи» Organism (`project.resetaura.io`).
Работает на Windows и macOS, хранит задачи локально и работает без интернета.

## Что умеет

- Окно без рамки: двигается за шапку, тянется за любой край и угол, запоминает положение и размер.
- Режимы окна: обычное, поверх всех окон, «на столе» (под остальными окнами).
- Блокировка: фиксирует положение и размер, чтобы виджет не сдвинуть случайно.
- Виды: «Мои задачи», «Мои на сегодня», «Все задачи» и каждый список Organism. Задачи сгруппированы по спискам, группы сворачиваются.
- Отметка выполнения с отменой, быстрое добавление (Enter), переименование двойным кликом.
- Правый клик по задаче: приоритет, срок, перенос в другой список, «не буду делать», открыть в Organism.
- Клик по названию раскрывает описание.
- Иконка в трее или строке меню: показать/скрыть, синхронизировать, выйти. Крестик прячет виджет, а не закрывает его.
- Автозапуск при входе в систему (в настройках), тёмная и светлая тема, прозрачность, размер текста.

## Как устроен офлайн

- Задачи хранятся на диске. Без сети виджет показывает последнее состояние.
- Изменения без сети попадают в очередь и показываются сразу. Очередь переживает перезапуск и уходит на сервер, как только появляется сеть (проверка раз в минуту, при возврате фокуса и при появлении сети).
- Задачи, созданные офлайн, помечены оранжевой точкой, пока не уйдут на сервер.
- Все виды считаются локально из одной выгрузки `GET /api/tasks`, поэтому офлайн работает любая вкладка.

## Авторизация

- Вход по email и паролю Organism (`POST organism.resetaura.io/api/auth/login`), один раз.
- Cookie-сессия хранится в файле, зашифрованном AES-256-GCM. Ключ лежит в Keychain (macOS) или Credential Manager (Windows).
- Когда access-токен истекает, виджет сам вызывает `/api/auth/refresh` и повторяет запрос.
- Каждый человек входит под собой и видит свои задачи. Если на том же компьютере войдёт другой человек, кэш и очередь предыдущего удаляются.
- HTTP-запросы идут из Rust, а не из webview, поэтому настраивать CORS на сервере не нужно.

## Используемые эндпоинты

| Действие | Запрос |
|---|---|
| Профиль | `GET /api/auth/me` |
| Списки | `GET /api/lists` |
| Задачи | `GET /api/tasks?sort=due&limit=500` |
| Создать | `POST /api/tasks` |
| Изменить | `PATCH /api/tasks/{short_id}` |
| Статус | `PATCH /api/tasks/{short_id}/status` `{status, wont_do}` |

## Сборка

Установщики собирает GitHub Actions (`.github/workflows/build.yml`):

1. Положи папку в репозиторий (отдельный или `apps/tasks-widget` в монорепо; во втором случае поправь пути в workflow).
2. Запусти workflow «Сборка виджета» вручную (Actions → Run workflow) или запушь тег `widget-v0.1.0`.
3. Скачай артефакты: `bioaura-tasks-windows` (`.exe`) и `bioaura-tasks-macos` (`.dmg`, универсальный для Intel и Apple Silicon).

Локально (нужны Node 20+ и Rust):

```bash
npm install
npm run tauri dev      # разработка
npm run tauri build    # установщик под текущую ОС
npm run dev            # только интерфейс в браузере, на тестовых данных (пароль: test)
```

## Установка на Mac

Сборка не подписана сертификатом Apple, поэтому при первом запуске macOS предупредит. Нужно либо открыть через правый клик → «Открыть», либо выполнить в терминале:

```bash
xattr -cr "/Applications/BIOAURA Tasks.app"
```

У виджета нет иконки в Dock: он живёт в строке меню, как TickTick.
